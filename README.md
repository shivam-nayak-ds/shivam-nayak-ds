## 🚀 Featured Systems & Products

### 📄 [Enterprise Insight RAG: Automated HR Analyst](https://github.com/shivam-nayak-ds/Semantic-Resume-Insight-RAG)
> *A high-precision GenAI system designed to eliminate manual resume screening.*
- **Architecture:** Built a **2-Stage Retrieval Pipeline** utilizing Vector Search + MS-MARCO Cross-Encoders to drastically reduce context hallucinations.
- **Tech Edge:** Leveraged Groq for ultra-low latency Llama-3 inference, ChromaDB for semantic search, and strict LLM metadata extraction for deterministic filtering.

### 🛡️ [Fraud-Shield-Engine: Real-Time API](https://github.com/shivam-nayak-ds/Fraud-detection-ml-system)
> *A low-latency endpoint system built to detect anomalous transactions in real-time.*
- **Architecture:** Engineered a scalable **FastAPI** backend to serve heavily optimized predictive models.
- **Tech Edge:** Successfully combated extreme dataset imbalance using **SMOTE** oversampling, ensuring high recall on edge-case fraudulent activities without sacrificing latency.

### 📈 [Retail Ops: Demand Forecasting MLOps Pipeline](https://github.com/shivam-nayak-ds/Retail-Ops-End-to-End-Sales-Forecasting-Pipeline)
> *An end-to-end predictive engine built for scalability and reproducibility.*
- **Architecture:** Designed a modular, production-ready pipeline bridging data ingestion, model training, and evaluation.
- **Tech Edge:** Integrated **MLflow** for rigorous experiment tracking and automated large-scale data versioning using **DVC**.
